# Can a different camera direction resolve an exact repeated-texture depth ambiguity?

The opposite view recovered many occluded pixels in the earlier study. This experiment addresses ambiguity among visible matches. Render the same reference layout at four cyclic assignments of discrete depth. On half of the surfaces the intensity pattern repeats every three pixels along the horizontal axis, with independently drawn texture across rows. The other surfaces repeat vertically. Match the reference to a horizontal camera and compare equally spaced extra cameras along the same horizontal axis and at a right angle. Every candidate gets the same 3 by 3 mean absolute error in each included image. Sum the two error arrays before selecting a depth. A mismatched perpendicular image from a different depth world controls for having a second patch array.

On the horizontally repeating surfaces, find corresponding reference pixels whose depth is 1 and 4 in the two counterfactual worlds and where both horizontal cameras give exactly zero patch cost to both depths in both worlds. Require these to be true unobstructed patches from their reference surface. Renderer ownership is used only to identify this scoring subset. An arm succeeds only if it assigns both depths correctly. Report all-foreground scores and results on horizontally and vertically repeating surfaces separately. Use 1,024 fresh layouts, resampling whole layouts, and require at least 500 eligible pixels, a perpendicular-view advantage of at least 20 points over both the same-axis and mismatched-image arms, and a lower 95% paired bound above zero for both contrasts. The point is a controlled orientation-specific cue in calibrated stereo, an established class of methods. No supervision or learned parameters enter the matcher.

# Can a reference photo choose the better direction on real tabletop scenes?

Run only if the common-visibility screen qualifies the two staged DTU scenes. Keep the previously nominated triplets and exposure 3. For every eligible reference view, select one of its two matched secondary cameras using only the reference image and the known candidate camera poses. Test the existing patch-repetition cue, a structure-tensor baseline using mean squared directional image gradients over the same crop, a baseline that chooses the larger transverse move, balanced random choice and each fixed direction. Evaluate both secondary images offline with the same estimator so every choice can be compared on the same frames. Use the better measured arm as a hindsight reference.

The two texture cues see the central 80% crop of the quarter-resolution, grayscale reference image. For the repetition cue, retain the registered 3×3 closest patch statistic over shifts of one, two and three pixels, along each candidate direction projected into the reference plane. Choose the camera with greater patch dissimilarity. The structure-tensor rule chooses the direction having the larger mean squared projected gradient. Neither rule can see the corresponding secondary photograph while choosing it.

Score a fixed sample of up to 512 common-visible reference pixels per triplet. Use floor-rounded quarter-resolution camera projections and a calibrated single-source plane sweep with 96 inverse-depth samples spanning 200–900 mm. Use 3×3 photometric patches and the same bilinear warp and zero-mean normalized cross correlation for every secondary camera. A projected structured-light point supplies the reference camera depth for scoring only. Report the fraction of predicted depths within 10 mm and the absolute depth error for the two scenes separately. Keep camera selections paired within each reference image. Include the hindsight gap. Advance to a broader panel only if the patch-repetition cue beats the better fixed direction and the structure-tensor route by at least five percentage points in each scene.

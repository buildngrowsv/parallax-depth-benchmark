# DTU supplied matched directions for all 49 screened camera positions

Every position in the common 49-camera robot trajectory matched a predominantly horizontal and a predominantly vertical candidate under the registered pose criteria. This uses only camera projection matrices. Visibility against the independent structured-light geometry and image-based depth accuracy are subsequent checks. The same camera path repeats across laboratory scenes. [Registered pose screen](PLAN.md) · [Matrices and selected view IDs](results/geometry.json) · [Official DTU dataset and citation terms](https://roboimagedata.compute.dtu.dk/?page_id=36)

The camera files were fetched by byte range from the official SampleSet archive. This kept the download limited to calibration entries. The next pilot draws 12 evenly spaced reference identities from the qualified path before viewing image or depth outcomes. It stages neutral-light exposure 3 from the archive's scans 1 and 6, the two structured-light point clouds, and the required projection matrices. The stage preserves a checksum manifest and keeps the source images and scans outside Git.

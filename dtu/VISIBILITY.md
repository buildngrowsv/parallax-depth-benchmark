# Qualify common structured-light visibility on the DTU pilot views

Use scenes 1 and 6 at the 12 evenly spaced reference positions already selected from pose geometry. Load the structured-light point cloud in the frame of the official projection matrices. Keep reference points projecting at least two working pixels inside each image. Work on a spatial grid downsampled by four. When several scan points hit a reference pixel, keep the frontmost. For each secondary image, compute a depth buffer from all valid projected points. Mark a reference point visible there when its projected pixel is inside the image and its depth differs from the frontmost projected depth by at most 5 mm. Count unique reference pixels visible in both candidates.

The pilot qualifies if at least eight triplets in each scene supply at least 500 shared reference pixels. Report independent horizontal and vertical coverage and their intersection. This geometric screen reads no pixel intensities and fits no photograph-based method. The projected point-cloud depth buffer provides an approximate common-visibility filter for an eventual photo-matching comparison. Independently measured point depths are reserved for evaluation.

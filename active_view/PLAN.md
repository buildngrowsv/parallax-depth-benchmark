# Can the first image choose the direction of the second?

Compare a camera direction selected from the reference image with the same two fixed directions and randomly chosen directions. Each method is allowed one translated photograph at the same displacement. The planner sees only the reference image and precisely which two camera directions are available. It asks which direction has less repeated patch content along the direction of displacement at separations of one to three pixels. Use the 20th percentile of per-pixel closest match distances as the scene score. Use the unchanged calibrated 3×3 matcher for every direction. Keep all depth and visibility variables inaccessible to the planner.

Draw 8,192 clean layouts and 8,192 layouts with independent Gaussian image noise of standard deviation .025. In each layout give one or three of the four surfaces horizontal periodicity and the rest vertical periodicity with the dominant axis randomly chosen. Use the same foreground texture distribution, four depth permutations, renderer and depths as the earlier orthogonal-camera test. Score one selected direction across all four counterfactual depth worlds for each layout. Render both directions offline for paired comparisons and measure a hindsight per-layout ceiling based on true depth. The planner earns no access to those counterfactuals.

Report pooled all-foreground accuracy and camera choice counts on each panel. Use a layout bootstrap of paired accuracy differences. The routing claim qualifies only if planning beats both fixed directions and per-layout random selection by at least 0.5 points with positive lower 95% bounds on both panels. Background identification for planning uses the observed intensity threshold specified in the code. These periodic synthetic textures deliberately establish variation in which direction could help. The measured improvement tests how much of that variation is predictable before acquisition. Record elapsed compute separately from camera count. Related work includes [multiple-baseline stereo](https://publications.ri.cmu.edu/a-multiple-baseline-stereo), [horizontal and vertical baselines](https://publications.ri.cmu.edu/experiments-in-multiple-baseline-stereo), and [uncertainty-driven view selection](https://arxiv.org/abs/2210.00978).
